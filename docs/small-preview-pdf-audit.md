# Small module browser/PDF baseline audit — PR 12a

**Scope:** All eight Small activities on `main` at v0.15.10, before PR 12a.
This is a **source-level rendering audit**, not a claim of screenshot-perfect
parity for modules intentionally left unchanged.

## Common geometry and typography

- Small slot: 2.4 × 2.6 in; default 0.1in inset all around.
- Physical printable area: **158.4 × 172.8pt**.
- PDF: `smallPdf.ts` uses embedded Mouse Memoirs, Nunito Medium/Bold and
  Zilla Slab Bold measured by `pdf-lib` with `fontkit`.
- Historically `SmallModulePreview.tsx` used responsive CSS font clamps,
  flex/grid rows, and independent browser word wrapping for every Small module.
  PDF used independent point-space baselines, wrapping and shrink-to-fit.
- PR 12a adds `smallParityLayout.ts` measured, pure top-left-space plans
  to **Multiple Choice** and **What Doesn't Belong**; the other Small
  module layouts are intentionally unchanged.

## Implemented in PR 12a

1. Browser and PDF for Multiple Choice and What Doesn't Belong use
   identical content, font widths, line breaks and top-left print coordinates.
   `mediumWidths()` provides Mouse Memoirs glyph measurements to the
   SVG preview; PDF uses the same embedded font's actual metrics.
2. Answer squares in Multiple Choice align with the **visible vertical
   center of the answer text**, not its first line's baseline; long answers
   may occupy up to three lines without overlapping neighboring options.
3. What Doesn't Belong retains its existing seeded shuffled word order
   but divides entries into left/right columns, measures their natural
   widths, and centers the combined group. Row positions are centered
   in the remaining space after the instruction.
4. The title reads **UNSCRAMBLE THE WORDS** without punctuation in both
   the original CSS preview and PDF.
5. No other Small activity renderer, validations, input limits, saved
   worksheets, sheet layout or Draw a Picture behavior is modified.
